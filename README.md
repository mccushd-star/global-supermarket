# GLOBAL SUPERMARKET

A responsive UAE-focused online supermarket storefront built with plain HTML, CSS, and JavaScript.

## Included in this demo

- UAE delivery-area selection and AED pricing
- Departments for fresh food, grocery, chilled and frozen foods, home, personal care, baby and kids, and electronics
- Search across product names, departments, brands, and descriptions
- Category, offer, price, and sorting filters
- Favorites and a persistent shopping basket
- Quantity changes, basket totals, delivery estimate, and free-delivery threshold
- Demo checkout with address, delivery-slot, and payment-method choices
- Delivery information, click-and-collect, help, and account-preview dialogs
- Responsive layouts for mobile and desktop

## Run locally

From this folder, run:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Demo boundaries

The product catalog and prices are illustrative, original sample content; this does not reproduce Carrefour's proprietary catalog or website. Accounts, inventory, store pickup, delivery slots, order tracking, customer support, and payment are front-end previews only. A production supermarket requires a secure backend and authorized integrations for those services.
